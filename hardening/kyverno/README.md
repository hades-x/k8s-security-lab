# Kyverno
Pinned chart 3.9.1 / app 1.19.1. Single admission replica is an intentional lab SPOF; fail-closed webhook downtime can block pod admission. ClusterPolicy is the requested API but deprecated by this release; plan CEL migration later.
install.sh installs the chart and FIVE ClusterPolicies in Audit. PSS remains Enforce, so Audit does not grant privileged pods in application namespaces. Platform host/resource policies exclude explicitly documented privileged namespaces; registry, image tag, token policies target application namespaces only. The netshoot repository is a narrow lab exception in the values allowlist.
Inspect reports, fix application manifests, then MODE=Enforce ./apply-policies.sh. Requests/limits cover init containers too; ephemeral containers cannot set resources and remain constrained by host/registry/tag controls.
Signature policy is prepared but NOT installed by default: verifyImages performs registry/network calls even in Audit mode and unavailable/unsigned images can break mutation. After P6 signs prod images and ensures TLS registry reachability, SIGNATURES=true MODE=Audit ./apply-policies.sh, then Enforce after positive and negative admission tests. Public key hardening/kyverno/cosign.pub; encrypted private key and password in .secrets, never tracked. Tlog ignored for this isolated private-key lab; no claim of transparency verification. Prod registry credentials/CA configuration must be coordinated with P6.
CLI tests exercise all validation rules offline, including optional fields, init/ephemeral containers, latest plus digest, implicit tags, and exemptions. Cryptographic verifyImages success requires a real signed OCI artifact and registry and is not represented by fabricated CLI results. Run test-signatures.sh on the deployed registry for that gate.
