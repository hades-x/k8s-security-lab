# Network isolation
Every application/normal scenario namespace has ingress+egress default-deny. DNS targets kube-dns in kube-system (UDP/TCP 53). app=app → app=db TCP 5432 has both directional grants. Traefik → app=app 8080, monitoring Prometheus → lab.k8s/metrics=true 9090. Confirm actual upstream pod labels; no namespace-wide ingress grant. Host-network Traefik would need a separately reviewed Cilium host/entity rule and is not silently allowed.
All allows are additive; a plain empty NetworkPolicy cannot override another allow. Quarantine uses Cilium ingressDeny/egressDeny from/to all, which overrides every allow including DNS. Pod exec stays available through the API/kubelet control path; response verification runs curl/dig inside the pod.
Template namespace demo is replaced programmatically by playbooks. Do not give app users permission to edit Cilium policies or remove quarantine labels. Existing flows may persist briefly; responses wait and re-test new connections. Scenarios temporarily grant narrow lab-only traffic and remove their explicit rehearsal grants during containment.
